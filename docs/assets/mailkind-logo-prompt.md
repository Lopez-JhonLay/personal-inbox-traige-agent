# Mailkind logo

Generated with the built-in imagegen tool. Final project asset:
`frontend/public/images/mailkind-logo.png`. The same transparent PNG is used in
the landing header/footer, app header, and browser favicon. The wordmark is rendered
as text beside the icon.

## Final prompt

Use case: logo-brand. Asset type: Mailkind website brand mark and browser favicon. Create ONE original square icon with a truly transparent background, no text or wordmark. A warm butter-yellow rounded-square paper tile with a simple ivory envelope in the center, bold charcoal outlines, a small gentle upward curve in the envelope flap suggesting kindness. The envelope must remain immediately recognizable at 16px. Match Mailkind's calm paper-and-ink design: butter yellow #ffe3a0, ivory #fffcf5, charcoal #22221e. Restrained, friendly and polished, flat vector-like raster artwork, smoothly rounded corners, consistent strong outlines, a tiny crisp offset shadow fully inside the canvas. Straight-on symmetrical composition, one mark occupying about 88 percent of the square canvas with narrow even transparent safe margins. No surrounding illustration, no desk, no letters, no extra symbols, no badges, no heart sticking outside the envelope, no gradients, no grain, no photorealism, no mockup sheet, no multiple options, no watermark. Deliver a clean 1024x1024 transparent PNG suitable for use unchanged as the site icon and favicon.
